# Decisions taken in the rebuild

Archive decisions are cited as D-numbers and live in the archive's `docs/DECISIONS.md`.
Each entry here records evidence, assumptions, rejected alternatives and the trigger that
would reopen it.

| # | Decision | Evidence and assumptions | Rejected | Reopen when |
|---|---|---|---|---|
| RB1 | One declared workspace root (`TENNISLAB_WORKSPACE`, default the current directory); every path resolves under it and containment is checked lexically, without following links. | The archive computed its root from each source file's location and 22 tracked files carried absolute paths (assessment §1). Lexical containment lets an equivalence workspace link read-only inputs from the archive while every write lands inside it. | Multiple read roots with an allowlist (more configuration, same guarantee); `Path.resolve()` containment (breaks the linked workspace). | A deployment needs inputs from more than one root. |
| RB2 | Code provenance is a package receipt (module name, file hash, package version), not a repository path. Config fields that pinned a module by path and hash are read and recorded as `declared_binding`; the package module runs. | 41 archive files imported modules by path at a pinned hash (assessment §1). A package cannot hash "the file that ran" by repository path. Data bindings keep their hash checks. | Verifying the archive file's hash against the package file (meaningless after a port). | A run needs to prove it executed a specific historical code version: use the git tag plus the receipt. |
| RB3 | Label barrier contract. Modules before `evaluation.report` may read outcomes only as history (state updates, training-year fits, membership) through one accessor, `chain.labels.LabelHistory`, with a declared purpose; only the report module computes a proper score on target-year outcomes. The test that runs the chain with the final target year's labels absent must pass for every stage before the report. | SCAR_TISSUE B1 asks for "the label file physically absent" before the report. In a walk-forward chain every target year is a training year of a later fold and the panel itself carries the outcome column, so literal absence is not attainable for the fit stage. The prospective situation is the final target year's outcomes being unknown; that is what the test encodes. | Physical absence for all stages (impossible for fits); per-fold processes (no equivalence with the accepted runs). | Lane C's leakage suite finds a pre-report score of a target year. |
| RB4 | Product commits carry the GitHub noreply address of the account `gh` is logged into. | R8 requires a GitHub-attributable email; the owner's GitHub email was not available in the session (`gh` token invalid) and the noreply address is attributable by construction. | The `.local` address (not attributable); guessing the account email. | The owner supplies the email: rewrite the short history with `git filter-repo --mailmap` before the first push. |
| RB5 | Provenance-only differences from the archive outputs are recorded as "explained", never patched to identical. | A launcher id, a code hash or a code path in a manifest is exactly the thing a port changes; forcing equality would mean writing the archive's values into the new code. Data outputs must be identical. | Emulating archive provenance strings. | Never. |
| RB6 | Data artifacts carry no wall-clock stamp; the stage manifest records start and finish times. | `edition_index.json` embedded `generated_at_utc`, so an otherwise identical rebuild could never be byte-identical and every downstream PENDING hash changed on each run. | Keeping the stamp behind a flag (two output shapes). | Never. |
| RB7 | Outputs that embed the hash of a rewritten source workbook are expected to differ from the archive on every row of that season, and are recorded as a cascade of one provenance difference, not as data differences. | The bridge rewrites the 2026 WTA tennis-data workbook; the archive's bytes carried openpyxl's wall-clock `docProps` timestamps, the rebuild's are fixed (RB6). `market_rows.csv` and both `panel.csv` files carry a `market_source_sha256` column, so 2,095 join rows and 1,945 panel rows differ in that one column only; every other cell reproduces. | Reproducing the archive's timestamps to force hash equality (would make the artifact wall-clock dependent again). | The column stops being a hash of the workbook bytes. |
| RB8 | Preserve existing authorship and remote history. For this handoff's new local commits use the explicitly supplied noreply email; do not rewrite or push. | Astra verified 31 baseline commits: 23 Gmail, 8 noreply; the configured remote already advertises an earlier commit. The handoff's all-noreply/no-remote/unpushed description is stale. This does not reopen the owner's R8 account decision or verify GitHub attribution. | Rewriting on the assumption nothing was pushed; guessing account state; changing global Git identity. | The owner explicitly requests an attribution repair or remote integration after reviewing the actual histories. |
| RB9 | Tier stages must join the synthetic acceptance path before a prospective full_tier campaign; preserve the existing sample as the baseline. | The accepted sample bypasses all tier stages, while full_tier is the strongest sports rung. Individual tier unit tests do not establish whole-chain mutation invariance. Native tier/SR02/sidecar T1 and full-bundle T3 remain requirements of Lane C2 integration. No change to tier_serve_counts_start_year is authorised by this decision. | Treating the non-tier sample as full_tier coverage; changing a frozen tier horizon to simplify a fixture. | A separately registered campaign deliberately excludes full_tier; retained historical equivalence still needs its existing tests. |
| RB10 | Keep frozen historical workspace bindings for reconstruction; Lane D creates a separate versioned update workspace and manifest-bound live config. | The two real chain descriptors consume archive-relative evidence paths. Replacing those paths in place would obscure the equivalence oracle. Reuse the existing single TENNISLAB_WORKSPACE root, immutable source versions and explicit output directories; no second root framework. | Reorganising archive work directories; silently pointing historical configs at the latest snapshot; adding a generic data registry. | A qualified source layout cannot be represented by the existing manifest/path contracts. |
| RB11 | SR03 forecast-only and complete label/read receipts are integration prerequisites under R9, not a Lane E scientific choice. Preserve baseline 180cb2d for historical equivalence; repair in a separately recorded revision and independently reconstruct it. | calibrate.py calls calibration.evaluate before the barrier; test_label_barrier only withholds the final target year; runner.py writes a static outcome_access flag. R9 and the independent C rejection invalidate the stronger barrier claim. Legitimate training and selection consume past outcomes relative to each fold; a global earliest-year ceiling would break the frozen walk-forward estimand. Require fold-specific read receipts and no emitted outer-year metrics before report; document that clarification before implementation. | Deferring the repair to a campaign; claiming removed metrics remain byte-identical; forbidding later folds from consuming legitimately past years; treating a returned key filter as physical non-access to all file bytes. | The repaired chain passes planted runtime leaks, unchanged forecast hashes and independent review; then close the prerequisite, retaining the historical warning. |
| RB12 | No archive integration commit or Lane C CI port until the lane evidence is reconstructable and each imported detector fails on its declared planted defect. | R15 rejects the original suite as comprehensive; no C2 report or negative-control acceptance table was present at handoff review. Lane A's existing reconstruction file is a prompt, not a completed review. Preserve lane-owned additions and the original C report; use separate reconstruction prompts/results. | Committing other lanes' untracked work on a status-only review; copying known false-negative gates into CI; equating a skipped test with a passed test. | A/C2 independent reports and per-test positive/negative evidence exist with clean write boundaries. |
| RB13 | Lane D treats event anchors as event identifiers, never as evidence that a result was available. Require an admissible result-date upper bound and receipt/publication qualification at the declared cutoff; quarantine unresolved overlapping history. | R12/UPDATE_SPEC describe D-2 on anchors but also require withholding unresolved overlaps. chronology.dating rejects EVENT_ANCHOR as availability evidence; the Canada regression shows why. Keep R6 historical equivalence unchanged and record live bounds separately; charter_asserted remains distinct under R13. | Releasing all final-round results at event start; treating an event-end bound as proof of publication; promoting a charter date to official after a spot check. | A permitted source qualifies per-match completion/publication timing, or a pre-registered sensitivity explicitly changes the cutoff. |

These are integration dispositions, not evidence that the pending repairs have been implemented. The archive rebuild directory contains `LANE_B_acceptance.md` and the implementation/reconstruction briefs.
